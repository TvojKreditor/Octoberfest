# Oktoberfest Birthday Party — приглашение со сбором ответов в Google Таблицу

Сайт-приглашение на 24.10.2026, 18:00 (Орбитальная, 90). Гость заполняет анкету о напитках, и **ответ сам попадает в вашу Google Таблицу**, пересылать текст в мессенджер не нужно. Ссылку на сайт даёт GitHub Pages, её можно отправить друзьям.

| Файл | Что это |
|---|---|
| `index.html` | Сам сайт. Его выкладываем на GitHub Pages |
| `apps-script.gs` | Код для Google Apps Script: принимает анкеты и пишет их в таблицу |
| `README.md` | Эта инструкция |

## Как это работает

1. Гость открывает сайт, заполняет анкету (за себя и, если нужно, за спутников) и отправляет её.
2. Страница отправляет ответ на ваше веб-приложение Google Apps Script. Его адрес записан в `index.html` в строке `SHEET_ENDPOINT`.
3. Скрипт пишет каждого человека отдельной строкой на лист **«Ответы»**:

   | Время | Имя | Пенное | Для тостов | Пожелания | Кто заполнил | Группа | Изменено | ID |
   |---|---|---|---|---|---|---|---|---|

   «Кто заполнил» пусто у того, кто заполнял за себя; у спутника там имя заполнившего. «Группа», «Изменено» и «ID» — служебные колонки (серым шрифтом).
4. Лист **«Сводка»** формулами считает, сколько человек выбрали каждый напиток и кто именно, и собирает все пожелания. Пересчитывается сам.

Если гость нажмёт «Изменить ответ», его строки **обновятся на месте**: «Время» первой отправки сохранится, в «Изменено» появится время правки. Убранный спутник удалится из таблицы. Дублей не будет.

## Шаг 1. Google Таблица

Создайте новую таблицу: откройте в браузере **sheets.new** и назовите её, например, «Oktoberfest 2026 — ответы гостей».

> Если Claude уже создал таблицу через коннектор, откройте её по присланной ссылке и переходите к шагу 2.

Листы и шапку делать не нужно: скрипт создаст всё сам на шаге 3.

## Шаг 2. Вставить скрипт

1. В таблице: меню **Расширения → Apps Script**. Откроется редактор с файлом `Код.gs`.
2. Удалите всё, что там написано, и вставьте целиком содержимое файла `apps-script.gs` (откройте его Блокнотом, Ctrl+A, Ctrl+C).
3. Нажмите значок дискеты **«Сохранить проект»** (или Ctrl+S). Название проекта вверху слева можно поменять на «Oktoberfest анкеты».

## Шаг 3. Один раз запустить `setup`

1. На панели над кодом в списке функций выберите **setup** и нажмите **«Выполнить»**.
2. Google попросит разрешение: **«Предоставить доступ»** (или «Проверить разрешения») → выберите свой аккаунт.
3. Появится предупреждение «Google не проверял это приложение». Для собственного скрипта это нормально: нажмите **«Дополнительные настройки»** → **«Перейти на страницу "Oktoberfest анкеты" (небезопасно)»** → **«Разрешить»**.
4. Внизу в журнале появится «Выполнение завершено». В таблице должны появиться листы **«Ответы»** (с шапкой) и **«Сводка»** (с нулями), а пустой «Лист1» исчезнет.

## Шаг 4. Развернуть как веб-приложение

1. Справа вверху: **«Начать развёртывание» → «Новое развёртывание»**.
2. Рядом с «Выберите тип» нажмите шестерёнку → **«Веб-приложение»**.
3. Заполните:
   - **Описание:** `Анкеты v1` (любое);
   - **Запуск от имени:** `Я (ваш адрес)`;
   - **У кого есть доступ:** **`Все`**. Важно: именно «Все», а не «Все, у кого есть аккаунт Google», иначе ответы гостей без входа в Google не дойдут.
4. **«Начать развёртывание»** (если снова спросит разрешение, разрешите, как на шаге 3).
5. Скопируйте **«URL веб-приложения»**. Он выглядит так:
   `https://script.google.com/macros/s/AKfycb…длинная-строка…/exec`
   Нужен адрес, который заканчивается на **`/exec`**. «Идентификатор развёртывания» не подойдёт.

**Проверка:** откройте этот URL в новой вкладке, лучше в режиме инкогнито (Ctrl+Shift+N). Должно показаться:
`{"ok":true,"message":"Приём анкет работает. …"}`
Если вместо этого Google просит войти, значит, в доступе выбрано не «Все». Исправьте это в «Управление развёртываниями».

## Шаг 5. Вставить URL в `index.html`

1. Правой кнопкой по `index.html` → **Открыть с помощью → Блокнот**.
2. Ctrl+F → найдите `SHEET_ENDPOINT`. В строке настройки кавычки пустые:
   ```js
   SHEET_ENDPOINT = ''
   ```
3. Вставьте свой URL **между кавычками**:
   ```js
   SHEET_ENDPOINT = 'https://script.google.com/macros/s/AKfycb…/exec'
   ```
4. Сохраните (Ctrl+S). Кодировку не меняйте: Блокнот сохраняет в UTF-8.

> Claude может вставить адрес сам — пришлите ему URL из шага 4.

## Шаг 6. Опубликовать на GitHub Pages

Через сайт GitHub, без консоли:

1. Зайдите на **github.com** под своим аккаунтом (TvojKreditor).
2. Справа вверху **«+» → New repository**.
   - **Repository name:** `oktoberfest` (латиницей);
   - **Public**: на бесплатном тарифе Pages работает только для публичных репозиториев;

3. На странице пустого репозитория нажмите ссылку **«uploading an existing file»** (или **Add file → Upload files**), перетащите **`index.html` с уже вставленным URL** → внизу **Commit changes**.
4. В репозитории: **Settings → Pages** (меню слева).

## Шаг 7. Обязательная проверка перед рассылкой

Страница отправляет анкету «вслепую»: ответа от Google она не видит и покажет «отправлено» даже тогда, когда адрес вставлен с ошибкой. Поэтому один раз проверьте руками:

1. Откройте **https://tvojkreditor.github.io/oktoberfest/** (лучше с телефона, не залогиненного в ваш Google).
2. Заполните анкету за себя и за одного «спутника», отправьте.
3. Через несколько секунд на листе «Ответы» должны появиться две строки, а «Сводка» должна посчитать их.
4. Нажмите на сайте «Изменить ответ», уберите спутника и отправьте ещё раз: в таблице должна остаться одна строка, с заполненным «Изменено».
5. Удалите тестовую строку: правой кнопкой по номеру строки → «Удалить строку».

Если строки не появились — см. «Если анкеты не доходят» ниже. Когда всё сработало, отправляйте ссылку друзьям.

## Где смотреть ответы

Таблица с ответами есть на компьютере и в приложении «Google Таблицы» на телефоне:
- **«Ответы»**: каждая строка — один человек.
- **«Сводка»**: сколько брать каждого напитка и кто его выбрал, плюс список пожеланий.

Ответы, которые кто-то уже прислал в мессенджер, можно вписать на лист «Ответы» вручную: имя, пенное, для тостов, пожелания. «Группу» и «ID» оставьте пустыми. Сводка учтёт и эти строки.

Колонки «Группа» и «ID» руками не меняйте: по ним скрипт находит строку гостя, когда тот правит ответ. Без них правка придёт новой строкой.

## Если что-то нужно поменять

- **Текст или оформление сайта.** Поправьте `index.html`, затем в репозитории **Add file → Upload files** → загрузите файл с тем же именем → Commit. Через 1–2 минуты сайт обновится.
- **Код скрипта.** После правки и сохранения: **Начать развёртывание → Управление развёртываниями → карандаш** → «Версия»: **Новая версия** → **Развернуть**. URL останется прежним. Если вместо этого сделать «Новое развёртывание», URL сменится, и его придётся заново вставить в `index.html`.
- **Список напитков.** Меняется в двух местах: в `index.html` и в массивах `FOAM` и `STRONG` в `apps-script.gs`. После этого обновите развёртывание (пункт выше) и ещё раз запустите `setup`: он пересоберёт «Сводку», ответы не тронет. Напиток, которого нет в списке скрипта, «Сводка» посчитает в строке «Другое».
- **Сломалась «Сводка»** (например, случайно стёрли формулы): запустите `setup` ещё раз.
- **Время в таблице сдвинуто.** В таблице: Файл → Настройки → Часовой пояс.

## Если анкеты не доходят

1. Откройте URL веб-приложения в режиме инкогнито: должно быть `"ok":true` (см. шаг 4). Если просит войти — в доступе не «Все».
2. Проверьте в `index.html`, что адрес вставлен целиком, заканчивается на `/exec` и стоит внутри кавычек `SHEET_ENDPOINT = '…'`.
3. Посмотрите, что пришло: в редакторе Apps Script слева значок **«Выполнения»**. Каждая анкета — строка `doPost`; если там ошибка, в ней написано, что не понравилось скрипту.
4. Если меняли код, а развёртывание не обновили, работает старая версия (см. «Код скрипта» выше).

## Что важно знать

- **Сайт публичный.** Его увидит любой, у кого есть ссылка, в том числе адрес Орбитальная, 90. Ссылку могут переслать дальше. Репозиторий тоже публичный: код виден, но секретов в нём нет.
- **Таблицу видите только вы.** Скрипт работает от вашего имени и записывает анкеты; прочитать через него ничего нельзя. Не включайте общий доступ к таблице, и чужие ответы никто не увидит.
- **Адрес веб-приложения виден в коде страницы**, так что теоретически кто-то может прислать мусорную анкету. Скрипт принимает только анкеты этого праздника, проверяет обязательные поля и обрезает длинный текст. Текст, похожий на формулу (`=…`), он записывает как обычный текст. Изменить или удалить чужие строки так нельзя: для этого нужны «Группа» и «ID», которые знает только браузер того гостя. Лишнюю строку можно просто удалить.
- **Изменить ответ** гость может с того же телефона или браузера, где заполнял анкету: страница помнит его анкету. С другого устройства получится новая анкета, и старую строку тогда удалите вручную.
